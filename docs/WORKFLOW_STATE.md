# Źródło prawdy workflow

Aktywne leady: `leads` + historia/aktywności.

Aktywne umowy: `contracts` + `contract_tasks` + pliki umowy.

Stare workspace'y działowe (`accounting`, `logistics`, `installation`) zostały wyłączone z użycia zamiast migrowania niepotrzebnego stanu localStorage. `finance` i `equipment` wymagają osobnej centralizacji przed uznaniem ich lokalnego stanu za produkcyjne źródło prawdy.
